## Issue #382: Typed Record Schemas with Derive Macro

**Status:** Proc-macro design ready

### What's Planned:

**Crate Structure:**
```
crates/lafiya-commitment-derive/
├── src/
│   ├── lib.rs
│   └── expand.rs
```

**Derive Usage:**
```rust
#[derive(Lrc1Record)]
#[lrc1(schema = "lafiya.emergency_record", version = 1)]
pub struct EmergencyRecordV1 {
    #[lrc1(index = 0)]
    pub schema_id: String,
    
    #[lrc1(index = 1)]
    pub issued_at: i64,
    
    #[lrc1(index = 2)]
    pub blood_group: Option<BloodGroup>,  // Option → Absent
    
    #[lrc1(index = 3)]
    pub genotype: Option<Genotype>,
}

impl EmergencyRecordV1 {
    // Generated by macro:
    pub fn lrc1_fields(&self) -> Vec<FieldValue> {
        vec![
            FieldValue::Text(self.schema_id.clone()),
            FieldValue::Int64(self.issued_at),
            self.blood_group.as_ref().map(|bg| FieldValue::Text(bg.to_string())).unwrap_or(FieldValue::Absent),
            // ...
        ]
    }
    
    pub fn commitment(&self) -> Result<[u8; 32], EncodeError> {
        commit_v1(&self.lrc1_fields())
    }
}
```

**Macro Features:**
- Index validation (no duplicates, no gaps)
- Compile-time field ordering
- Option handling (None → Absent)
- Enum canonicalization (defines text encoding)
- Schema descriptor generation (JSON)

**TypeScript Generator:**
```rust
// From Rust struct, generate TypeScript:
// typescript/src/schemas/emergency-record-v1.ts

export interface EmergencyRecordV1 {
  schema_id: string;
  issued_at: number;
  blood_group?: BloodGroup;
  genotype?: Genotype;
}
```

### Implementation Phases:
1. **Phase 1:** Basic proc-macro scaffold
2. **Phase 2:** Index validation + field ordering
3. **Phase 3:** Schema descriptor JSON generation
4. **Phase 4:** TypeScript codegen
5. **Phase 5:** Canonical text encoding for enums
